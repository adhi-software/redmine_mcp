# Redmine MCP

A Redmine plugin that provides access to Redmine data through the MCP tool.


## Installation

- Extract the zip file into the `redmine/plugins` directory.

## Compatibility Matrix

| Redmine Version | Plugin Version |
|-----------------|----------------|
| 7.0.x            | 1.0           |

---

## Release Notes for v1.0

- **Features**
  ```text
   - Supports get, create, and update tools.
  ```
---

## Available MCP Tools

| Category | MCP Tools |
|----------|-----------|
| **Projects** | `list_projects`, `get_project`, `update_project`, `archive_project`, `unarchive_project`, `close_project`, `list_project_memberships`, `get_membership`, `create_membership`, `update_membership` |
| **Issues** | `list_issues`, `get_issue`, `create_issue`, `update_issue`, `list_issue_relations`, `get_issue_relation` |
| **Spent Time** | `list_time_entries`, `get_time_entry`, `create_time_entry`, `update_time_entry`, `list_time_entry_activities` |
| **Users** | `list_users`, `get_user` |
| **Groups** | `list_groups`, `get_group`, `create_group`, `add_group_user` |
| **Roles** | `list_roles`, `get_role` |
| **Files** | `list_files`, `get_attachment` |
